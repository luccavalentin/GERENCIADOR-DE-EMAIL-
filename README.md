# Agilliza Gerenciador de E-mail

Sistema profissional para gerenciamento e monitoramento de e-mails, com integração IMAP/SMTP e painel de controle administrativo.

## Autoria

## Tecnologias
- TanStack Start (React 19)
- Supabase
- IMAPFlow / Nodemailer
- Tailwind CSS

## Desenvolvimento Local
```sh
npm install
npm run dev
```
